# BlueMetal (bluemetal.ai) verification - 2026-11-06 (public pages only, nothing purchased/called)

Sources: https://bluemetal.ai/ ; /docs ; /docs/skill.md ; /terms ; /privacy ; https://api.bluemetal.ai/openapi.yaml ; https://fromyou.ai/

1. Price: Real documented API price, not just marketing. $0.0095/song flat, any length, debited only on success; failed/canceled not charged. Prepaid credits, no overage/invoice in v1. New accounts $0.10 promo (~10 songs), no card. Web credit-pack sizes/min top-up/taxes/FX fees: NOT FOUND (only agent endpoint /v1/credits/purchase: $5.00-$1,000 via Stripe). Docs table inconsistent: 100 songs = $0.85 (docs) vs $0.95 (homepage). ~INR 0.8-0.9/song before Stripe/FX/GST -> under INR 1 only if no failures/retries overhead and card fees on top-ups are small.
2. Supplied lyrics: No separate lyrics field ("retired lyrics/duration field" returns 400). Exact lyrics go inside the single 2,000-char prompt; text is first rewritten by an LLM ("prompt preparation"), so exact-lyric fidelity not guaranteed. No guarantee documented.
3. Names/pronunciation: not found. Nothing on pronunciation control; name only via prompt text.
4. Languages: only samples English, Spanish, Japanese; "any language" claimed. Hindi/Tamil/Telugu/Bengali/Marathi/Kannada/Malayalam/Gujarati/Punjabi: not found, unverified.
5. Commercial use: Terms say BlueMetal does not claim ownership; outputs may not be unique, may not be copyrightable; no clearance guarantee; user responsible. No explicit commercial-license grant or indemnity.
6. Output: mp3 (192 kbps), wav, flac; 48 kHz stereo; ~2-4 min (docs also say 3-5); no duration control (a short personalised clip cannot be requested; cost flat anyway).
7. Latency: not published. Example in docs 40s for a 178s song (illustrative only). "Varies with song and demand."
8. API: REST JSON, Bearer key (bm_live_), OAuth2.1, async+poll, HMAC webhooks, sync mode up to 90s (else 202), Idempotency-Key, OpenAI-compatible /v1/audio/speech, MCP server, OpenAPI spec. Keys via dashboard sign-in (GitHub/email) - I did not sign up.
9. Limits: 10 concurrent, 60 writes/min, 600 reads/min; 402 on no credit; 503 no_capacity (queue full, not billed); failed jobs retried once automatically; not charged. No SLA; Terms: availability/quality/duration not guaranteed.
10. Privacy: Every prompt (incl. lyrics/names) goes via OpenRouter to Meta Muse Spark 1.3 Contributor; Terms/Privacy say prompts and generated text MAY BE USED TO IMPROVE META PRODUCTS INCL. AI MODELS; "not zero-retention or no-training". Audio stored 30 days on Cloudflare R2; presigned URLs bearer-accessible. Uploaded audio input: not supported. Compute provider (RunPod per /health enum) unnamed in policy.
